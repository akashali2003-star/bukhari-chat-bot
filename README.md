# Starter Agent

This project is a simple Python-based agent scaffold that runs from the terminal and responds to prompts.

## Features

- Minimal conversational agent loop
- Modular design in the `src` package
- Easy to extend for real LLM integrations or task automation

## Run it

```bash
python main.py
```

## Example

```text
You> hello
Agent> Hello! I’m your starter agent. Ask me anything or tell me what you want to build.
```

## Extend it

You can connect this agent to an API, add memory, or build tool-calling behavior as your project grows.
